The actual problem

The engine is the strong part: retrieval, span binding, verification, the audit chain, replay. All of that is built and gated. What's missing isn't capability — it's cohesion. Today Cairn is 16 scripts and five separate HTML pages that never link to each other, plus a CLI and an MCP server.

The shape it wants to be

One console, five panes, following the work rather than the code.

The one structural gap

Cairn has no input channel for the expert whose judgment it exists to support. There is exactly one way for a human conclusion to enter the system today: hand-editing a JSON sidecar. That sidecar is not append-only, and it has already lost a confirmation you gave — your FIG-2 "A" was overwritten by a single-engine machine read and is unrecoverable.

This is also what blocks the deliverable from being complete. A record of inquiry without the reviewer's adjudications documents the machine's half of the work only.

Sequence

Ordered by what unblocks what, not by size.

Next

Close stage 4's foundation — append-only adjudication

Small, and everything downstream waits on it. It fixes a live defect (a lost confirmation), unblocks the deliverable's missing section, and is the prerequisite for the drawing-correction feature. Nothing else should go first.

Then

The console shell — one page, five panes

Not a rewrite. The four existing HTML generators already produce the content; this gives them a shared frame, persistent corpus context in the header, and navigation between them. The single highest-leverage change to how the tool feels.

Then

Ask-in-the-console, and the review queue

The front door: pose a question, watch the outcome resolve, see its evidence, accept or annotate it. This is the point where Cairn stops being a set of generators and starts being a tool a professional sits inside.

Then

Finish the patent pack — PE-2's §112 checks, VER-1's operations

Domain depth for the live engagement, once the surface can display it.

Later

Replay UI (M5), third corpus, Layer-E cadence

Replay is the demo no competitor can give — re-derive a dated answer against an archived hash, live. Worth building when there is someone to show it to.

Waiting on you

  • Trademark clearance on Cairn — the packet is written; it needs an attorney, not me.
  • Intake Q13 / Q16 — which deliverable, in what form. The report is built content-agnostic so your answer refines it rather than invalidating it.
  • One hour of blind annotation — the only honest recall measure, and it expires per sheet the moment you view an overlay. Worth doing right after the append-only store lands.
  • ~$4 Layer-E run — the first that would report the decision-versus-evidence gap.
